# meal-management-client

לקוח React מינימלי לשרת MealManagement. מטרתו להראות שהשרת עובד מקצה לקצה: התחברות, רשימת ארוחות עם pagination מהשרת, פרטי ארוחה עם לקיחת מנות, טיפול ב-409, צ'אט ומתכונים.

## הרצה
דרישות: Node.js 18 ומעלה, והשרת `MealManagement.API` רץ על `https://localhost:7012`.

```
npm install
npm run dev
```
ואז לפתוח `http://localhost:5173`.

כתובת השרת מוגדרת בקובץ `.env` (`VITE_API_URL`). אם מופיע "אין חיבור לשרת", לפתוח פעם אחת את `https://localhost:7012/swagger` בדפדפן ולאשר את תעודת הפיתוח.

משתמשי דמו: `admin@meals.local` / `Admin123!` ו-`user@meals.local` / `User123!`.

## טיפול בהתנגשות (409)
כשמשתתפת לוחצת "אני מכינה" על מנה שמשתתפת אחרת כבר עדכנה, השרת מחזיר 409. הלקוח מציג הודעה בולטת ("המנה נלקחה או עודכנה על ידי משתתפת אחרת") וטוען מחדש את טבלת המנות כדי להציג את הכמות העדכנית (`src/pages/MealDetailsPage.jsx`, הפונקציה `handleError`). ההתנגשות עצמה מזוהה בשרת ולא בלקוח.

## מבנה
- `src/api/client.js`: מופע axios יחיד. מוסיף `Authorization: Bearer`, ו-401 מעביר למסך ההתחברות.
- `src/pages`: התחברות, דף בית, הוספת ארוחה, רשימת ארוחות ופרטי ארוחה.
- `src/components`: שורת מנה, בחירת מאכלים, צ'אט (משיכה כל 3 שניות עם `afterId`) ומתכונים.
